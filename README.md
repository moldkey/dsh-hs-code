<p align="center"><strong>dsh-hs-code — HS 编码查询与归类提示</strong></p>

查章节、拆品目/子目，按关键词给归类方向。

## 安装

    dsh plugin --profile web add github:moldkey/dsh-hs-code

## 工具

- `hs_chapter_lookup`：章号/编码查询
- `hs_keyword_hint`：关键词 → 候选章

## 说明

章节标题为简写；归类与税率以海关税则和归类裁定为准。

更多工具：https://deepseekbase.com/zh/tools/
